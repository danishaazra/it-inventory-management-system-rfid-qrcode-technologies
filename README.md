# IT Inventory Management System Using RFID & QR Code Technologies

A web-based IT inventory management system developed to improve asset tracking, maintenance management, and inspection workflows through the integration of RFID and QR Code technologies.

## Overview

This project was developed to address challenges associated with manual IT asset management, including inaccurate records, limited asset visibility, and delays in maintenance and inspection processes.

The system provides a centralized platform for managing IT assets, tracking their status, scheduling maintenance, conducting inspections, and generating reports. It can be accessed through both desktop and mobile web browsers.

## Key Features

* Secure role-based authentication
* IT asset registration and tracking
* Bulk asset import using Excel files
* RFID and QR Code integration for quick asset identification
* Maintenance task creation and scheduling
* Weekly, monthly, and quarterly maintenance schedules
* Asset inspection workflows
* Inspection status and notes management
* Reporting and analytics
* Centralized IT asset information management

## RFID & QR Code Integration

The system supports two methods for identifying and inspecting IT assets:

* **RFID:** Uses an Arduino Uno with an RC522 RFID module for asset identification.
* **QR Code:** Allows users to scan asset QR Codes using a mobile device for quick access to asset information.

Both methods allow IT department staff to identify assets efficiently and record inspection information directly through the system.
